# **App Name**: Puneet & Ritu Wedding Invitation

## Core Features:

- Elegant Invitation Display: Display wedding details (groom, bride, date, venue) with a traditional theme, including the Ganesh mantra.
- Countdown Timer: Real-time countdown to the wedding date (February 19, 2026).
- Responsive Design: Ensure the invitation looks beautiful and functions perfectly on all devices (desktop, tablet, mobile).
- Firebase Deployment: Automated deployment to Firebase Hosting for easy access via a unique URL (puneetritu.web.app).

## Style Guidelines:

- Primary color: Rich maroon (#800000) to evoke a sense of tradition and elegance.
- Background color: Light peach (#FAF0E6), a very lightly desaturated tone of maroon, creating a warm and inviting backdrop.
- Accent color: Metallic gold (#D4AF37) for highlights, text, and decorative elements to symbolize prosperity and celebration.
- Headline font: 'Playfair', a modern sans-serif font, with high contrast and an elegant feel.
- Body font: 'PT Sans', a humanist sans-serif font for readability and a touch of warmth, used in conjunction with 'Playfair' for longer text sections.
- Use traditional Indian wedding motifs (e.g., Kalash, Diya, Shehnai) as decorative icons, rendered in gold.
- Implement a clean, centered layout with balanced spacing, optimized for readability and visual appeal on all screen sizes.
- Subtle animations, like a gentle fade-in effect, can be used to enhance the user experience without being distracting.
